## Canvas

Use case: ui-mockup
Asset type: preview-only visual design concept, wide desktop web app
Primary request: Design a polished large 2D interactive tech ecosystem map titled "Ralf's builder atlas". Full-screen React Flow-like node canvas, front-facing flat screenshot, no perspective or devices. Light warm canvas, subtle dot grid, crisp dark typography, restrained sage, blue and lavender category regions. Strong information design, ample spacing, readable labels.
Composition: top bar with "Explore" and "Build a project". Main map 80% width; narrow selected-tool inspector right. Three clearly named overarching territories: PRODUCT, PLATFORM, WORKSHOP. Within PRODUCT: Interface (React, Next.js, shadcn/ui, Tailwind CSS, next-intl), Data (TanStack Query, Drizzle, Neon), Intelligence (AI SDK, ElevenLabs, Keyframe Labs), Logic (Effect), Business (Stripe, Resend, PostHog). PLATFORM: Deployment (Vercel, Cloudflare, Kubernetes), Provisioning (Stripe Projects). WORKSHOP: Code (Codex, Claude Code, Bun), Workspace (Omarchy, Raycast, Migadu, Glove80, Samsung ultrawide).
Only a few meaningful thin connections, each with a tiny explicit relationship label: Next.js builds on React; Drizzle queries Neon; Next.js deploys to Vercel. Do not connect unrelated tools just for decoration. Inspector selected Next.js: "Build a web app", "React framework", "Builds on React", "Can deploy to Vercel". Bottom corner minimap and zoom controls. Professional editorial engineering aesthetic, inviting and understandable to a beginner. The category labels should dominate over brands. No fake charts, no metrics, no gradients, no 3D.

## Illustrated atlas

Use case: infographic-diagram
Asset type: preview-only illustrated atlas design concept
Primary request: A beautiful large landscape 2D cartographic diagram of a personal technology ecosystem, titled "A builder's world". A thoughtful illustrated map that makes software categories memorable. Flat top-down editorial cartography, warm paper background, subtle organic territory shapes with gentle muted colors, precise modern typography, tiny tasteful line illustrations of screens, databases, cloud servers and a split keyboard. No photorealism, no isometric perspective.
Composition: three clear lands with generous negative space, PRODUCT at center, PLATFORM to the right, WORKSHOP along bottom. Each land contains readable named districts and individual labeled tool stops. PRODUCT districts: "Build interfaces" with React, Next.js, shadcn/ui, Tailwind CSS, next-intl; "Store information" with Drizzle, Neon, TanStack Query; "Add intelligence" with AI SDK, ElevenLabs, Keyframe Labs; "Run the business" with Stripe, Resend, PostHog; "Structure logic" with Effect. PLATFORM districts: "Run and deliver" with Vercel, Cloudflare, Kubernetes; "Provision services" with Stripe Projects. WORKSHOP districts: "Create software" with Codex, Claude Code, Bun; "Work environment" with Omarchy, Raycast, Migadu, Glove80, Samsung ultrawide.
Use one accent walking route labeled "An example web app" that visits Next.js, Drizzle, Neon, Vercel, presented as an illustrative journey rather than mandatory dependencies. Other tools sit in their districts without spaghetti edges. Readable detailed map with a small legend: "District = a problem area" and "Stop = a tool". Be sophisticated, more information design than fantasy map, no castles, no decorative landmarks unrelated to technology. All typography readable, no invented brands or metrics.
